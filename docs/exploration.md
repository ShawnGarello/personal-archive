# Visual exploration

Status: proposed exploration process. No direction boards, mockups, or models have been produced yet.

## What stays consistent

A precise, curated personal archive with a case-file feeling. A cabinet opens, a folder comes forward, and readable pages present the work. Labels, page structure, and photographic previews should be intentional and orderly.

Explore composition and the object's setting before polishing materials. Use the same fictional sample project in each public concept so the comparison is about design. Never use private reference documents, screenshots, contact details, or extracted text in public boards or external image-generation prompts.

## Round 1: Compare three compositions

| Candidate | Entrance composition | Folder destination | Main question |
| --- | --- | --- | --- |
| A: Cabinet portrait | One cabinet at a three-quarter angle, with a clearly readable label and opening handle | A pull-out writing shelf | Can one strong object establish personality and make the next action obvious? |
| B: Drawer close-up | A tightly framed drawer front; opening reveals a deliberate arrangement of folder tabs | A writing surface immediately below the drawer | Does the close view provide enough spatial context while getting to the work quickly? |
| C: Archive workstation | Cabinet and adjacent writing surface appear together in a wider composition | The adjacent surface, already visible on arrival | Does the visible destination make the journey clearer without distracting from the portfolio? |

These are options within the confirmed theme. Materials, lighting, colors, typefaces, and final object proportions are still open.

For each candidate, create an entrance frame and a reading frame using a small reference board and rough visual mockups. A sketch or generated concept image is sufficient to compare composition; it is not a final asset or evidence that the interaction works.

## Round 2: Develop the selected scene

Draw a storyboard with five frames: arrival, drawer opening, folder selection, folder placement, and cover opening. Mark camera position, focal point, object movement, and the moment readable web content becomes interactive. Compare a phone composition alongside the desktop view.

Resolve where the folder rests and how the camera reaches that position before detailed modeling. Test page hierarchy with realistic placeholder text lengths. Preserve direct access to work and contact information.

## Round 3: Define the visual language

Use the chosen composition to select cabinet material, folder construction, label treatment, paper appearance, photograph borders, typography, lighting, and accent colors. Compare these as a coherent set rather than selecting each in isolation.

Use Polaroid-style imagery as project previews, with clear titles and captions. Preserve an enlarged, uncropped view for technical screenshots. Show a project summary and a longer detail page in the design study.

## How to choose

- Identity: does the scene feel like a precise personal archive?
- Clarity: can a new visitor identify the owner and the next action?
- Reading: is a real project easy to scan once the folder is open?
- Continuity: do the folder and camera move through a believable space?
- Adaptability: does the composition work on a phone and with reduced motion?
- Feasibility: can the scene be built and loaded without unnecessary environmental detail?

Choose based on these questions, then record the direction and tradeoffs in the decision log. A visually dramatic entrance cannot compensate for an unreadable folder.

## Private content preparation

Use the local resume to draft a content map inside `private/`: possible introduction, project candidates, experience summaries, and facts needing clarification. Review that map with the owner before copying approved wording into tracked files. The public exploration materials can proceed with placeholders while this review happens.

## Completion

Exploration is ready to feed the first implementation prototype when one entrance composition, one readable folder layout, a camera storyboard, a phone adaptation, and the visual language have been selected. Production geometry, a full site, and final animation are later deliverables.
